# Examples

Example input files for FROST.

| Directory | Case |
| --- | --- |
| `interfrostT1/` | InterFrost T1, 1D freezing with phase change |
| `interfrostTH2/` | InterFrost TH2, thawing of a frozen inclusion with and without a hydraulic gradient |
| `fieldCase/` | Field case, seasonal surface temperature with optional localized heating |

These examples were run with the MOOSE version of 26 September 2025. Other versions may require changes to the input files or give slightly different results. These examples, like the software, are provided in the hope that they will be useful, but without warranty of any kind.
